# chmonitor v0.3.8 — launch film

30s, 1920×1080, 30fps. Built with HyperFrames (one GSAP timeline in `index.html`),
same light canvas, fonts and music grid as `hero-film/` v2.

| t | Scene |
|---|---|
| 0–4 | Intro: v0.3.8 · 34 features, 96 fixes, 6 perf |
| 4–8 | Advisor: unread tables, unread columns, unused projections |
| 8–12 | Detached parts triage (isometric figure, four review classes) |
| 12–16 | Hot query shapes for one table |
| 16–20 | Insights: repeated OPTIMIZE, heavy TTL merges, retention forecast, codec check |
| 20–24 | Alert repeat reminders: cooldown, mute, back-off |
| 24–28 | Montage of other features |
| 28–30 | End card |

Table names and numbers in the panels are illustrative, not from a real cluster.

`assets/figures/triage-bench-light.svg` is generated by `assets/figures/build.mjs`
(anatomy skill kit): `node build.mjs --light`.

## Render

See the root README "Render prerequisites" first (Git LFS, FFmpeg).

```bash
npx hyperframes check
npx hyperframes render -q delivery -f 30 -o renders/chmonitor-v0.3.8-launch.mp4
```
